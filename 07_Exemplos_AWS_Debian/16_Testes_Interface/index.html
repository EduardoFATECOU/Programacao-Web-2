Testes de Interface com React Testing Library

Testes de componentes React simulando interações do usuário

Como Executar

cd 16_Testes_Interface
npm install
npm test

Tecnologias utilizadas:

  • Jest — runner de testes
  • React Testing Library — renderização de componentes
  • userEvent — simulação de interações (clique, digitação)
  • jsdom — ambiente de navegador simulado

Exemplo: Teste do Formulário

import { render, screen } from '@testing-library/react';
import userEvent from '@testing-library/user-event';
import Formulario from '../components/Formulario';

describe('Componente Formulario', () => {
  test('deve desabilitar botão quando campo está vazio', () => {
    render();
    expect(screen.getByTestId('btn-enviar')).toBeDisabled();
  });

  test('deve exibir sucesso ao enviar', async () => {
    render();
    await userEvent.type(screen.getByTestId('campo-nome'), 'Maria');
    await userEvent.click(screen.getByTestId('btn-enviar'));
    expect(screen.getByTestId('sucesso'))
      .toHaveTextContent('Cadastro realizado!');
  });
});
Dica: Prefira userEvent em vez de fireEvent para simular interações reais do usuário. userEvent.type() dispara os eventos keyDown, keyPress, input e keyUp sequencialmente, como um usuário real faria.
