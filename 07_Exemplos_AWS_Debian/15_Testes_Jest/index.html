Testes Unitários com Jest

Projeto Node.js com testes reais — execute localmente

Estrutura do Projeto

15_Testes_Jest/
├── package.json
├── index.html
├── src/
│   └── funcoes.js
└── __tests__/
    └── funcoes.test.js

Como Executar

cd 15_Testes_Jest
npm install
npm test

Ou em modo watch (re-executa ao salvar):

npm run test:watch

Funções Testadas

FunçãoDescrição
somar(a, b)Soma dois números
subtrair(a, b)Subtrai dois números
ehPar(numero)Verifica se número é par
validarCPF(cpf)Valida CPF (dígitos verificadores)
calcularMedia(notas)Calcula média de um array

Exemplo de Teste

import { somar, ehPar } from '../src/funcoes.js';

describe('Funções matemáticas', () => {
  test('somar(2, 3) deve retornar 5', () => {
    expect(somar(2, 3)).toBe(5);
  });
});

describe('Função ehPar', () => {
  test('deve retornar true para números pares', () => {
    expect(ehPar(2)).toBe(true);
    expect(ehPar(0)).toBe(true);
  });

  test('deve retornar false para números ímpares', () => {
    expect(ehPar(3)).toBe(false);
  });
});
Padrão AAA (Arrange, Act, Assert):
  1. Arrange — prepara os dados (const a = 2, b = 3)
  2. Act — executa a função (const resultado = somar(a, b))
  3. Assert — verifica o resultado (expect(resultado).toBe(5))
