Bem-vindo à Home

Esta é a página inicial da SPA. A navegação é feita via hashchange sem recarregar o navegador.

O histórico de navegação é preservado automaticamente (botão Voltar do navegador funciona).

Dica: Clique nos links e use os botões Voltar/Avançar do navegador.

Sobre este projeto

Esta SPA (Single Page Application) foi construída com JavaScript puro para demonstrar o conceito de roteamento no lado do cliente.

  • Técnica: Hash-based routing (#)
  • Evento: window.addEventListener('hashchange', ...)
  • Histórico: Navegação nativa do navegador preservada
  • Sem recarregamento: A página nunca recarrega
