CI/CD — Integração e Entrega Contínua

Automatização de testes, build e deploy com GitHub Actions

O que é CI/CD?

CI — Integração Contínua

Automatiza a execução de testes e verificação de qualidade a cada push ou pull request. Garante que o código novo não quebre o projeto.

CD — Entrega Contínua

Automatiza o deploy da aplicação para produção após a aprovação dos testes. Entrega rápida e confiável de novas versões.

Pipeline Completo (.github/workflows/deploy.yml)

name: CI/CD - Deploy

on:
  push:
    branches: [main]        # Dispara ao fazer push na main
  pull_request:
    branches: [main]        # Dispara ao abrir PR para main

jobs:
  build-and-test:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout do código
        uses: actions/checkout@v4

      - name: Configurar Node.js 20
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'

      - name: Instalar dependências
        run: npm ci             # Instala versões exatas (package-lock.json)

      - name: Executar testes
        run: npm test           # Falha se testes não passarem

      - name: Build de produção
        run: npm run build      # Gera pasta dist/

      - name: Deploy no GitHub Pages
        uses: peaceiris/actions-gh-pages@v3
        if: github.ref == 'refs/heads/main'
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./dist

Explicação do Pipeline

PassoDescrição
on: pushDefine quando o pipeline é acionado (push na main ou PR)
runs-on: ubuntu-latestAmbiente Ubuntu mais recente para executar os passos
actions/checkout@v4Faz o checkout do código do repositório
actions/setup-node@v4Instala a versão especificada do Node.js (20)
npm ciInstala dependências exatas (mais rápido e confiável que npm install)
npm testExecuta a suite de testes — se falhar, o pipeline para
npm run buildGera o build de produção na pasta dist/
peaceiris/actions-gh-pagesFaz o deploy da pasta dist/ para o GitHub Pages

Estrutura Mínima para CI/CD

meu-projeto/
├── .github/
│   └── workflows/
│       └── deploy.yml      # Pipeline CI/CD
├── src/
├── public/
├── package.json            # Com scripts "test" e "build"
├── vite.config.js          # Configuração do build
└── .gitignore

Requisitos no package.json:

npm install --save-dev jest @testing-library/react
npm install --save-dev vite @vitejs/plugin-react

Resumo: CI/CD automatiza testes + build + deploy. Cada push na main dispara o pipeline. Se todos os testes passarem, o build é gerado e o deploy é feito automaticamente. Isso garante entregas rápidas, consistentes e sem erros manuais.
