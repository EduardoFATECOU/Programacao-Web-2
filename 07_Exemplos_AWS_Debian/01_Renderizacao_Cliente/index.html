Renderização: Servidor vs Cliente

Entendendo a diferença entre server-side rendering (SSR) e client-side rendering (CSR)

Renderização no lado do servidor (SSR): O servidor processa o HTML e envia a página pronta.
Renderização no lado do cliente (CSR): O navegador recebe um HTML mínimo e o JavaScript constrói a interface.

Simulação SSR

O HTML já vem completo do servidor. Clique no botão para "simular" o carregamento.

Página carregada:

<html>
  <body>
    <h1>Olá, visitante!</h1>
    <p>Bem-vindo ao site.</p>
    <ul>
      <li>Item 1</li>
      <li>Item 2</li>
      <li>Item 3</li>
    </ul>
  </body>
</html>

Simulação CSR

O HTML é mínimo. O JavaScript constrói a interface após o carregamento.

HTML inicial recebido:

<html>
  <body>
    <div id="root"></div>
    <script src="app.js"></script>
  </body>
</html>
