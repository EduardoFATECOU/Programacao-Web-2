Git — Controle de Versão

Comandos fundamentais e fluxo de trabalho com branches

1. Configuração Inicial

git config --global user.name "Seu Nome"
git config --global user.email "seu@email.com"
git config --global init.defaultBranch main

2. Criar / Clonar Repositório

# Criar novo repositório local
git init

# Clonar repositório remoto
git clone https://github.com/usuario/projeto.git

3. Ciclo de Alterações

# Verificar status
git status

# Adicionar à staging area
git add arquivo.js
git add .              # Todos os arquivos

# Criar commit
git commit -m "Mensagem descritiva"

# Ver histórico
git log --oneline --graph
Fluxo: Working Directory → git add → Staging Area → git commit → Repositório

4. Trabalho com Branches

# Listar branches
git branch

# Criar nova branch
git branch feature-login

# Mudar para branch
git checkout feature-login

# Criar e mudar (atalho)
git checkout -b feature-login

# Mesclar na branch atual
git checkout main
git merge feature-login

# Deletar branch
git branch -d feature-login

5. Repositório Remoto

# Adicionar remote
git remote add origin https://github.com/usuario/projeto.git

# Enviar alterações
git push -u origin main
git push origin feature-login

# Baixar alterações
git pull origin main

# Buscar sem mesclar
git fetch origin

6. .gitignore e Boas Práticas

Arquivo .gitignore — impede que arquivos desnecessários sejam versionados:

node_modules/
dist/
.env
*.log
.DS_Store
.vscode/
  • Commits pequenos e atômicos (uma mudança lógica por commit)
  • Mensagens descritivas no presente imperativo ("Adiciona...", "Corrige...")
  • Nunca commitar senhas, tokens ou .env
  • Sempre puxar (git pull) antes de começar a trabalhar
  • Usar branches para cada funcionalidade
  • Fazer code review via Pull Requests

Fluxo de Trabalho Completo (Git Flow Simplificado)

# 1. Criar branch para nova funcionalidade
git checkout -b feature/minha-funcionalidade

# 2. Desenvolver e commitar
git add .
git commit -m "Implementa nova funcionalidade"

# 3. Voltar para main e atualizar
git checkout main
git pull origin main

# 4. Integrar a funcionalidade
git merge feature/minha-funcionalidade

# 5. Enviar para o repositório remoto
git push origin main

# 6. (Opcional) Deletar branch da funcionalidade
git branch -d feature/minha-funcionalidade
