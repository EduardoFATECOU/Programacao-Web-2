Cypress — Testes End-to-End

Capítulo 3 Prova 3 — Q4, Q8

O que é Cypress?

Cypress é uma ferramenta moderna para testes de interface (E2E). Diferente dos testes unitários (Jest), que testam funções isoladas, o Cypress abre um navegador real e simula interações do usuário: cliques, digitação, navegação, etc.

Estrutura do Exemplo

  • src/index.html — App de exemplo (login + lista de tarefas)
  • cypress/e2e/login.cy.js — Testes de login
  • cypress/e2e/tarefas.cy.js — Testes da lista de tarefas
  • cypress.config.js — Configuração do Cypress

Como Executar

1. Instalar dependências

cd 20_Cypress
npm install

2. Iniciar o servidor do app

npm run server

O aplicativo estará disponível em http://localhost:3000

3. Executar os testes

Modo interativo (recomendado):

npm run test:open

Isso abre o Test Runner do Cypress. Clique em "E2E Testing", escolha um navegador e clique nos arquivos de teste.

Modo headless (linha de comando):

npm run test

Os resultados aparecem no terminal. Vídeos e screenshots são salvos em cypress/videos/ e cypress/screenshots/.

Código dos Testes

login.cy.js

describe('Página de Login', () => {
  beforeEach(() => {
    cy.visit('/');
    cy.get('[data-view="login"]').click();
  });

  it('deve exibir o formulário de login', () => {
    cy.get('input[type="email"]').should('be.visible');
    cy.get('input[type="password"]').should('be.visible');
    cy.get('button[type="submit"]').should('contain', 'Entrar');
  });

  it('deve exibir erro para credenciais inválidas', () => {
    cy.get('input[type="email"]').type('invalido@email.com');
    cy.get('input[type="password"]').type('senha_errada');
    cy.get('button[type="submit"]').click();
    cy.contains('Credenciais inválidas').should('be.visible');
  });

  it('deve exibir dashboard ao fazer login com sucesso', () => {
    cy.get('input[type="email"]').type('admin@email.com');
    cy.get('input[type="password"]').type('123456');
    cy.get('button[type="submit"]').click();
    cy.contains('Bem-vindo, admin!').should('be.visible');
  });
});

tarefas.cy.js

describe('Lista de Tarefas', () => {
  beforeEach(() => {
    cy.visit('/');
    cy.get('[data-view="tarefas"]').click();
  });

  it('deve permitir adicionar e remover tarefas', () => {
    cy.get('#nova-tarefa').type('Estudar Cypress');
    cy.get('#btn-adicionar').click();
    cy.contains('Estudar Cypress').should('be.visible');

    cy.get('input[type="checkbox"]').first().check();
    cy.contains('Estudar Cypress').should('have.class', 'concluida');

    cy.get('.remover').first().click();
    cy.contains('Estudar Cypress').should('not.exist');
  });
});

Comandos Cypress Usados

  • cy.visit() — Navega para uma URL
  • cy.get() — Seleciona elementos por seletor CSS
  • cy.contains() — Seleciona elemento pelo texto
  • .type() — Digita em um campo de texto
  • .click() — Clica em um elemento
  • .check() — Marca um checkbox
  • .should() — Faz asserções sobre o elemento

Dicas

  • Com Cypress, você pode depurar os testes visualmente — cada passo fica registrado no Test Runner
  • Use cy.clock() para controlar o tempo e cy.intercept() para simular APIs
  • Sempre prefira testar comportamentos visíveis ao usuário, não detalhes de implementação
  • Mantenha os testes independentes — cada teste deve funcionar isoladamente
