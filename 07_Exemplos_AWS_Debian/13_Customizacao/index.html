Customização de Frameworks CSS

Variáveis CSS, tema claro/escuro, Bootstrap customizado e classes utilitárias Tailwind

Bootstrap Customizado

As variáveis CSS abaixo alteram o Bootstrap sem recompilar SASS:

:root {
  --bs-primary: #e65c00;
  --bs-primary-rgb: 230, 92, 0;
  --bs-secondary: #2c3e50;
  --bs-border-radius: 0.75rem;
}
Alert personalizado: cor e borda arredondada alteradas via variáveis CSS.

Tema Claro / Escuro

Troca entre temas usando data-theme e variáveis CSS:

:root {
  --bg-color: #ffffff;
  --text-color: #1a202c;
}
[data-theme="dark"] {
  --bg-color: #1a202c;
  --text-color: #e2e8f0;
}
Claro
Escuro

Tailwind CSS Customizado

Com Tailwind, cores e espaçamentos são configurados via tailwind.config.js:

// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      colors: {
        primary: '#e65c00',
      },
      spacing: { '18': '4.5rem' },
    },
  },
}
bg-[#e65c00]
bg-[#7c3aed]
bg-[#059669]

Cores arbitrárias com sintaxe bg-[#cor]
